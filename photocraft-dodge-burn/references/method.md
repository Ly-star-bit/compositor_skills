# 每个数字是怎么来的

[SKILL.md](../SKILL.md) 和 [regions.md](regions.md) 的展开版：脚本怎么从 PhotoCraft 给的五个点画出区域、量什么、线怎么找、每一笔怎么定，以及这些数字是在哪里量出来的。数字都是在 photocraft-cli 0.19.0 上量的；`tests/run.sh brush` 每次都把画笔重新量一遍。

## 通过 MCP 用到的命令

| 做什么 | 命令 |
|---|---|
| 找人脸 | `image.detectFaces`：每张脸五个点（两只眼睛的中心、鼻尖、两个嘴角）。`rightEye` 是画面左边那一只 |
| 中性灰层 | `layer.new.layer`，`mode: "Soft Light"`，`fillNeutral: true`（填充柔光的中性色，50% 灰） |
| 双曲线 | `layer.newAdjustmentLayer.curves`（压暗 `[[0,0],[128,96],[255,255]]`，提亮 `[[0,0],[128,160],[255,255]]`），`layer.setProps` 设成明度混合，`layer.layerMask.hideAll` 把蒙版填黑 |
| 画 | `paint.stroke`：`points`、`size`、`hardness: 0`、`opacity`、`flow: 1`、`color`，`target` 是 `pixels`（灰层）或 `mask`（曲线的蒙版）；用 `command_batch` 一次送 60 笔 |
| 看画面 | `doc_save` 存成 PNG 再读回来：画之前一次，建好空图层后一次（确认空图层不改变画面），画完一次 |

## 画笔量出来是什么样

在一张 50% 灰的画布上量的（硬度 0、流量 100%）：

- **一个笔点**：中心的变化 = 不透明度 × 到白色（或黑色）的距离（不透明度 0.4 的白点把 128 提到 178）。形状是高斯：标准差 = 笔的直径 × 0.235（半径一半处剩 0.56，半径处剩 0.10，1.25 倍半径以外是 0）。
- **一笔线**：沿线每一处都正好是这一笔的不透明度，笔点互相重叠也不会超过；横向比单个笔点宽（半径处还剩 0.44）；两端各多出约半个半径。
- **两笔叠在一起**：第二笔加在第一笔上面（0.3 两次 = 0.51）。所以每条纹只画一笔，不分段；`circles` 和 `troughs` 的笔会在眼下叠加。
- **柔光灰层**：白色不透明度 a 把灰度提到 0.5 + 0.5a，亮度变化 = a ×（这里的皮肤在柔光下最多能提多少）。所以 `不透明度 = 想提的亮度 ÷ 柔光在这里能提的亮度`。曲线的蒙版同理：`不透明度 = 想提的亮度 ÷ 整条曲线在这里能提的亮度`。
- 实测：黑眼圈、法令纹每一笔"想提多少"和"实际提了多少"相差不到 2 级（脚本每次打印）。

## 区域：从五个点画出来

两眼中心的距离记作 d。眼睛的宽度取 0.45 d（下面叫"眼宽"），脸宽取 2.3 d；"横向"是从画面左边的眼睛指向右边的眼睛，"向下"垂直于它、指向嘴。所有形状都跟着头的倾斜转。鼻尖偏离两眼中线多少，就是头转了多少：鼻子的根部按它的一半修正。

- **脸的范围**：以"两眼中点向下 0.45 个眼到嘴的距离"为中心的椭圆，半宽 1.1 d（到太阳穴），半高 1.3 个眼到嘴的距离。
- **皮肤**：取两侧脸颊（眼睛下方一个眼宽处）的颜色做样本，在脸的范围里找颜色相近的像素（Lab 的 a、b 在 3.5 个标准差以内，亮度从比样本暗 45 到亮 30）。"要匀的皮肤"去掉眼睛、眉毛、鼻子、嘴；"会反光的皮肤"只去掉眼睛、眉毛、嘴（鼻子留着）。
- **额头、脸颊、下巴**：额头是眼睛连线以上 0.62 个眼宽之外；下巴是嘴以下 0.55 个嘴宽之外（下唇下面那道凹是形，不算）；脸颊是两者之间、离中线 0.2 d 以外。
- **眼下**：以"眼睛中心向下 0.39 个眼宽"为中心的一弯（0.55 × 0.28 个眼宽），去掉眼睛本身。它的亮度和"紧挨着它外面一圈、眼睛下方的皮肤"比，不和脸颊的高光比（和高光比，每个人的眼窝都像黑眼圈）。
- **各条纹路的搜索范围**：泪沟在眼睛中心向下 0.5 个眼宽的一弯里；鱼尾纹在外眼角以外 0.92 个眼宽处的一块；眉间纹在两眼中点向上 0.38 个眼宽的一小块；抬头纹在整个额头；嘴角纹在嘴角外下方 0.62 个眼宽处；法令纹沿着"鼻翼旁 → 嘴角外侧下方"一条向外鼓的弧线，宽 0.45 个眼宽。

## 线怎么找

- **"这里有多暗"**：亮度在"0.35 个眼宽的模糊"和"0.04 个眼宽的模糊"之间的差（只在皮肤里平均）。带正负号，不截断：眉间、鼻梁这些高光区里的一条纹，仍然比整张脸的平均亮，但它还是一条纹。
- **"这条线比两旁暗多少"**：线上的暗度，减去两旁的暗度。两旁各在 0.09、0.14、0.2 个眼宽三处里取最亮的一处（鱼尾纹几条挨得很近，不能把旁边那条纹当成皮肤）。脸颊本身的明暗过渡两旁一样暗，量出来是 0。这就是表里纹路各项的数。
- **法令纹**：沿着那条弧线，每一段在两侧 0.3 个眼宽内找最暗的位置，平滑成一条线，取其中"比两旁暗 2 级以上"的最长一段（至少弧线的五分之一）。
- **其余五项**：在搜索范围里找"亮度沿横切方向向上弯"的地方（亮度二阶导数矩阵的较大特征值，尺度 0.035 个眼宽），方向要和这一项该有的方向一致（抬头纹横着 ±25°，眉间纹竖着 ±30°，嘴角纹向下 ±40°，泪沟横着 ±50°，鱼尾纹向外 ±55°）；连成片后，够长、够细长的才算一条线，取中线。方向允许范围大的项按方向分成三组各自连片，从一点散开的几条鱼尾纹才不会连成一团。
- **不算纹路的**：线上 30% 以上的点不在皮肤上，或紧挨着的两侧（0.12 个眼宽）不是皮肤（法令纹除外：它本来就贴着嘴和鼻子）；比两旁暗不到 2 级；暗过 34 级（头发、睫毛、边缘）；额头的皮肤有三成以上都是线（那是刘海）。

## 每一项量什么、画什么

- **肤色不匀**（`forehead`、`cheeks`、`chin`）：亮度在"脸宽/150"和"脸宽/36"两个模糊（只在皮肤里平均）之间的差。和周围差 13 级以上的（痣、纹）逐渐不动，到 28 级完全不动；亮度沿一个方向阶跃的地方（鼻侧、下颌线、发丝）不动；离皮肤边缘三个"脸宽/36"以内不动。量的数 = 这个差在区域内部的平均绝对值。画法：把"要加回去的亮度"（份额 0.9 × 档位）拆成笔点，三种笔径（标准差 = 脸宽/36、/72、/144），每种里从最合适、最明显的位置画起，画一个就从"还差多少"里减掉它；额头最多 80 个、脸颊 110 个、下巴 50 个，每个不超过 15 级。
- **黑眼圈**：量的数 = 眼下那一弯比周围皮肤暗多少（0.15 个眼宽的模糊后）。画法：每只眼一笔，沿眼下横着 0.56 个眼宽长，笔径 0.62 个眼宽，提亮量 = 0.5 × 档位 × 量到的数。
- **纹路**：每条线一笔，笔径 0.12 个眼宽（法令纹 0.16）。提亮量 = 0.5 × 档位 × 25 级 × tanh(线的深浅 ÷ 25 级)：浅纹提掉一半（全量时），越深提得越少，线再深提亮量也不超过 12.5 级。
- **油光**：亮度比"脸宽/14 的模糊"高出 18 级以上、颜色的鲜艳程度又比这张脸的皮肤低的地方。量的数 = 这些地方平均比周围亮多少（面积不到皮肤的三百分之一时算 0）。画法：笔点，份额 0.4 × 档位，每个不超过 10 级，最多 40 个。
- **立体感**：固定的几笔，位置由五个点定：鼻梁一笔（+4 级）、额头一笔（+3）、两侧苹果肌各一笔（+3）、下巴一点（+3）、鼻梁两侧各一笔（−3）、颧骨下各一笔（−3）；`some` 是这些数的一半。不在皮肤上的笔丢掉。
- 任何一笔最多改变 15 级亮度；几笔叠加后某处超过 24 级时脚本警告。

## 档位和 `auto` 的门槛

`clear` 1、`some` 0.5、`none` 0。`auto`：量到的数低于第一个门槛 → `none`，否则 `some`；达到第二个门槛只是在表里提示"明显，可以考虑全量"，`auto` 自己不取全量。门槛见 regions.md 末尾的表。它们是起步值，定在下面这几张照片上，没有经过用户逐张验收：

| collins（刘海盖住额头，在笑） | 0 | 3.3→2.6 | 2.6→1.6 | 7.9→5.6 | 2.2→1.4 | 3.8→2.5 | 0 | 15.2→10.3 | 28.1→26.4 |

"画完再量"用的是画之前的同一块皮肤、同一条线，所以两个数比的是同一样东西。

## 做不到的

- 只有五个点，没有脸的轮廓和五官的形状：大侧脸、低头仰头很厉害、五官被挡住时区域会偏。所以流程里要先读区域图核对。
- 皮肤范围靠颜色：和肤色接近的头发、暖色背景可能被算进去；很深的阴影里的皮肤可能被漏掉；黑白照片上分不开皮肤和头发。
- 分不清眼妆和黑眼圈、表情纹和皱纹、妆面的高光和油光：靠门槛挡掉一部分，其余靠看图的人判断。
- 找线会漏：纹太浅、太短、贴着五官或被头发挡住时找不到，找不到就不画。也会错：皮肤上的一根发丝两旁都是皮肤，可能被当成纹（暗过 34 级的才被挡掉）。
- 肤色不匀用笔点近似，比整张算出来的图粗（笔点合起来画出想要的变化的七到九成）。
- 立体感的位置是估的，没有验收。
- 眼睛间距不到 70 像素的脸不处理。只改明暗，不改颜色。只修脸。

## 测试

`tests/run.sh`（只用命令行，没有窗口）：

| 套 | 查什么 |
|---|---|
| `pin` | photocraft-cli 的版本和校验值与旁边两个技能一致 |
| `plan` | `--needs` 的写法（项、组、`all`、后写的盖过先写的）；`auto` 的门槛、从不取全量；脸的方向（正、歪、倒）；各区域的位置和互不重叠；笔点拆分；什么算一条纹 |
| `brush` | 画笔重新量一遍：笔点的高度和宽度、线、叠加 |
| `look` | 每一项都打印；写出整脸和三张放大图；不写成品；没有脸时说明 |
| `paint` | 中性灰：图层结构和名字、每一笔落点、画完再量各项都降了一部分、只有脸上变了、放大图齐全；降档重跑变轻；全部不修不写文件；只做立体感；手给五个点 |
| `lines` | 在测试人像上画四条它没有的纹（眉间、鱼尾、泪沟、嘴角）：都被找到、`auto` 取一半、全量后变浅但还在；没画的地方不多出线 |
| `curves` | 双曲线：两个曲线层和蒙版、落点、明度混合不偏色 |
| `guards` | 不覆盖原图、别人的文件、用户改过的成品 |
| `document` | 分层文档作为输入：原文档不动，图层保留在下面 |
| `encoding` | 中文路径、GBK 环境 |

测试照片是 compositor-retouch 的测试用的那张 NASA 标准照。
